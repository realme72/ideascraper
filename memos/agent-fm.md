## What they do

Agent FM is a desktop application that acts as a group chat and command center for software engineers working with multiple AI coding agents. Instead of checking terminal windows or reading through raw logs, engineers get streaming text and audio status updates from their agents, resolve blockers, and issue instructions in one feed.

## Team

Agent FM is led by co-founders Aniket Deshpande (CEO, formerly Applied AI at Meta Superintelligence Labs) and Mugdhaa Patankar (CTO, formerly at Snowflake, Twitch, and AWS). Both have strong technical backgrounds in large technology companies, though neither has a documented prior founding exit.

## Market

The target buyers and users are software developers and engineering teams currently juggling multiple local and cloud AI coding agents (such as Claude Code and Codex). It emerges from the recent surge in agentic coding workflows where managing several simultaneous agent sessions creates an oversight bottleneck.

## Risks

- Integrated development environments (IDEs) like Cursor or VS Code, or model providers like Anthropic and OpenAI, could build multi-agent orchestration directly into existing developer workflows, eliminating the need for a standalone desktop client.
- Engineers may prefer terminal-based multiplexers or lightweight CLI tools over a proprietary audio-and-chat desktop application.
